# План аварийного восстановления и миграции Proxmox VE (PVE)

Данный регламент описывает процесс резервного копирования виртуального окружения на второй сервер (PBS), изменения дисковой конфигурации основного сервера с 4x SSD на 2x SSD (RAID 1), восстановления ОС и разворачивания виртуальных машин.

---

## Этап 1. Резервное копирование виртуальных машин

*Все действия выполняются в веб-интерфейсе основного сервера Proxmox VE.*

1. Перейдите в **Datacenter** -> **Storage** -> **Add** -> **Proxmox Backup Server**.
2. Подключите второй сервер (PBS), указав его IP-адрес, логин, пароль и Fingerprint (отпечаток ключа).
3. Перейдите в **Datacenter** -> **Backup** -> Нажмите **Add** (Добавить задание).
   * **Storage**: Выберите подключенный `PBS`.
   * **Selection Mode**: `All guests` (Все виртуальные машины и контейнеры).
   * **Mode**: `Snapshot` (Снимок на лету, без остановки сервисов).
4. Выделите созданное задание в списке и нажмите кнопку **Run now** (Запустить сейчас).
5. Дождитесь статуса `Task OK` для всех машин.

---

## Этап 2. Резервное копирование конфигурации Proxmox VE

*Действия выполняются в консоли (Shell) основного сервера Proxmox VE.*

1. Создайте архив критически важных настроек гипервизора (база данных кластера, конфигурация ВМ и сетевые интерфейсы):
   ```bash
   tar -czf /root/pve-settings.tar.gz /etc/pve /etc/network/interfaces
   ```
2. Скачайте полученный файл `/root/pve-settings.tar.gz` на свой рабочий компьютер (через WinSCP / FileZilla) или перенесите его на второй сервер по SSH.

---

## Этап 3. Модификация дискового массива (Железо)

1. Корректно завершите работу основного сервера (`poweroff`).
2. Извлеките все 4 старых SSD-накопителя из слотов.
3. Установите **2 SSD по 800 ГБ** в первые два слота. Два оставшихся диска уберите на полку в качестве холодного резерва (ZIP).
4. Включите сервер, зайдите в утилиту управления RAID-контроллером HPE Smart Array (через Intelligent Provisioning или SSA).
5. Удалите старый массив и создайте новый **RAID 1 (Зеркало)** из двух установленных дисков.

---

## Этап 4. Чистая установка и восстановление ОС Proxmox VE

1. Установите чистую ОС Proxmox VE с флешки на новый RAID 1 массив.
   * **Важно:** Укажите точно такое же имя хоста (Hostname) и тот же IP-адрес, которые были у сервера до обслуживания.
2. После завершения установки зайдите в консоль (Shell) нового сервера.
3. Загрузите ранее сохраненный файл `pve-settings.tar.gz` обратно в папку `/root/`.
4. Восстановите конфигурацию командой:
   ```bash
   tar -xzf /root/pve-settings.tar.gz -C /
   ```
5. Отправьте сервер в перезагрузку:
   ```bash
   reboot
   ```
*После перезагрузки Proxmox VE восстановит свой прежний вид, пароли, сетевые настройки и автоматически подтянет связь со вторым сервером (PBS).*

---

## Этап 5. Восстановление виртуальных машин из бэкапа

1. Откройте веб-интерфейс ожившего Proxmox VE.
2. В левом дереве ресурсов выберите подключенное хранилище второго сервера (`PBS`).
3. Перейдите во вкладку **Backups**.
4. Выберите первую виртуальную машину в списке и нажмите кнопку **Restore** (Восстановить).
5. В открывшемся окне в качестве целевого хранилища (**Storage**) укажите ваш новый локальный массив из SSD.
6. Нажмите **Restore** и повторите операцию для остальных машин.
7. После успешного скачивания запустите виртуальные машины.
